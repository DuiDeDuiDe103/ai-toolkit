# 说明书目录

本目录包含 ai-toolkit 各工具的说明书。

## 工具列表

| 工具 | 说明书 | 说明 |
|------|--------|------|
| disk_clean | [disk_clean.md](disk_clean.md) | 磁盘扫描工具 |

## 使用方式

Agent 可以通过读取说明书来了解如何调用工具：

1. 识别用户需求（关键词匹配）
2. 读取对应工具的说明书
3. 按照说明书调用工具
4. 解析输出并给用户建议
